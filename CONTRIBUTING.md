# Contributing to FloweringAgents

FloweringAgents is open source and community-built. Every contribution is a bloom in the garden.

## Ways to contribute

- **Code** — FastAPI backend, Next.js frontend, Python/Node SDK, ZKP circuits (circom), Docker/Nginx infra
- **Design** — UI improvements, mobile, accessibility
- **Docs** — API docs, architecture diagrams, translations (DE / SR / EN covered by founder)
- **Community** — Bug reports, feature suggestions, helping others in issues

## Getting started

1. Fork the repo
2. `git clone` your fork
3. `cd infra && docker compose up -d` (once backend exists)
4. Open a PR with a clear description

## Spirit

FloweringAgents is not a competition — and neither is contributing to it.  
A typo fix is as welcome as a new feature.  
The only requirement: contributions align with the core spirit — transparent, honest, open.
